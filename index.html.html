🥤 Lesson 21: Digital 7 Manipulative

Shake it • Spill it • Move it • Make a counting path

Seven counters! Try moving them into a scattered arrangement.
Teacher routine: Shake & Spill → ask “How many?” → choose Counting Path → click 1, 2, 3, 4, 5, 6, 7 → rearrange → ask “Is it still 7?”
Counting Path mode requires clicking the counters in order. Move Counters mode lets you drag them anywhere.
